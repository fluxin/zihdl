# ZIO instruction set

Generated by `zig build isa-doc` from `examples/protocol_emulator/isa.zig`; do not edit.

Every instruction is 32 bits: opcode `[31:28]`, payload `[27:16]`, delay `[15:0]`; it occupies delay + 1 cycles. The core has 4 GPIO pins. An encoding outside these tables faults before any side effect. Reserved fields are ignored.

## JMP (opcode 0)

Jump to `target` when `cond` holds; X_DEC/Y_DEC decrement only when taken.

| Field | Bits | Values |
|---|---|---|
| `target` | `[23:16]` | 0..255 |
| `cond` | `[26:24]` | `ALWAYS`=0, `NOT_X`=1, `X_DEC`=2, `NOT_Y`=3, `Y_DEC`=4, `PIN_HIGH`=5, `OSR_NOT_FULL`=6 |
| `reserved` | `[27:27]` | reserved |

## WAIT (opcode 1)

Stall until pin `index` matches `cond`, then hold for the delay.

| Field | Bits | Values |
|---|---|---|
| `index` | `[19:16]` | 0..3 (any when `cond`=0) |
| `reserved` | `[25:20]` | reserved |
| `cond` | `[27:26]` | `CYCLES`=0, `PIN_LOW`=1, `PIN_HIGH`=2 |

## IN (opcode 2)

Shift one four-pin sample into the ISR; every eighth sample writes an RX word.

| Field | Bits | Values |
|---|---|---|
| `count` | `[20:16]` | 4..4 |
| `source` | `[23:21]` | `PINS`=0 |
| `reserved` | `[27:24]` | reserved |

## OUT (opcode 3)

Shift `count` bits (0 means 16) out of the OSR, LSB first, autopulling an empty OSR.

| Field | Bits | Values |
|---|---|---|
| `count` | `[20:16]` | 0..16 |
| `target` | `[23:21]` | `PINS`=0, `X`=2, `NULL`=4 |
| `reserved` | `[27:24]` | reserved |

## PULL (opcode 5)

Load the OSR from the TX FIFO; `block` stalls on an empty FIFO, otherwise it flags underrun.

| Field | Bits | Values |
|---|---|---|
| `block` | `[16:16]` | 0..1 |
| `reserved` | `[27:17]` | reserved |

## MOV (opcode 6)

Copy `src` to `dest`, optionally bit-inverted.

| Field | Bits | Values |
|---|---|---|
| `src` | `[18:16]` | `PINS`=0, `X`=1, `Y`=2, `NULL`=3, `ISR`=4, `OSR`=5 |
| `dest` | `[21:19]` | `PINS`=0, `PIN_DIRS`=1, `X`=2, `Y`=3, `ISR`=4, `OSR`=5 |
| `op` | `[22:22]` | `NONE`=0, `INVERT`=1 |
| `reserved` | `[27:23]` | reserved |

## SET (opcode 7)

Write the immediate `value` to `target`.

| Field | Bits | Values |
|---|---|---|
| `value` | `[20:16]` | 0..31 |
| `target` | `[23:21]` | `PINS`=0, `PIN_DIRS`=1, `X`=2, `Y`=3 |
| `reserved` | `[27:24]` | reserved |
