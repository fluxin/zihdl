# ZIO instruction set

Generated by `zig build isa-doc` from `examples/protocol_emulator/isa.zig`; do not edit.

Every instruction is 32 bits: opcode `[31:28]`, payload `[27:16]`, delay `[15:0]`; it occupies delay + 1 cycles. The core has 4 GPIO pins. An encoding outside these tables, or with a nonzero reserved field, faults before any side effect.

## JMP (opcode 0)

Jump to `target` when `cond` holds; X_DEC/Y_DEC decrement only when taken.

| Field | Bits | Values |
|---|---|---|
| `target` | `[23:16]` | 0..255 |
| `cond` | `[26:24]` | `ALWAYS`=0, `NOT_X`=1, `X_DEC`=2, `NOT_Y`=3, `Y_DEC`=4, `PIN`=5, `TX_PENDING`=6, `X_NE_Y`=7 |
| `reserved` | `[27:27]` | reserved, must be 0 |

## WAIT (opcode 1)

Stall until pin `index` matches `cond`, then hold for the delay.

| Field | Bits | Values |
|---|---|---|
| `index` | `[19:16]` | 0..3 (any when `cond`=0) |
| `reserved` | `[25:20]` | reserved, must be 0 |
| `cond` | `[27:26]` | `CYCLES`=0, `PIN_LOW`=1, `PIN_HIGH`=2 |

## IN (opcode 2)

Shift `count` bits (0 means 32) of `source` into the ISR in the configured direction; autopush writes an RX word at the threshold.

| Field | Bits | Values |
|---|---|---|
| `count` | `[20:16]` | 0..31 |
| `source` | `[23:21]` | `PINS`=0, `X`=1, `Y`=2, `NULL`=3, `ISR`=4, `OSR`=5 |
| `reserved` | `[27:24]` | reserved, must be 0 |

## OUT (opcode 3)

Shift `count` bits (0 means 32) out of the OSR in the configured direction, autopulling an empty OSR from the TX FIFO.

| Field | Bits | Values |
|---|---|---|
| `count` | `[20:16]` | 0..31 |
| `target` | `[23:21]` | `PINS`=0, `PIN_DIRS`=1, `X`=2, `Y`=3, `NULL`=4, `ISR`=5 |
| `reserved` | `[27:24]` | reserved, must be 0 |

## PUSH (opcode 4)

Write the ISR as one RX word and clear it.

| Field | Bits | Values |
|---|---|---|
| `reserved` | `[27:16]` | reserved, must be 0 |

## PULL (opcode 5)

Load the OSR from the TX FIFO; `block` stalls on an empty FIFO, otherwise it flags underrun.

| Field | Bits | Values |
|---|---|---|
| `block` | `[16:16]` | 0..1 |
| `reserved` | `[27:17]` | reserved, must be 0 |

## MOV (opcode 6)

Copy `src` to `dest`, optionally inverted or bit-reversed. MOV ISR empties the ISR count; MOV OSR fills the OSR count.

| Field | Bits | Values |
|---|---|---|
| `src` | `[18:16]` | `PINS`=0, `X`=1, `Y`=2, `NULL`=3, `ISR`=4, `OSR`=5 |
| `dest` | `[21:19]` | `PINS`=0, `PIN_DIRS`=1, `X`=2, `Y`=3, `ISR`=4, `OSR`=5 |
| `op` | `[23:22]` | `NONE`=0, `INVERT`=1, `REVERSE`=2 |
| `reserved` | `[27:24]` | reserved, must be 0 |

|---|---|---|
